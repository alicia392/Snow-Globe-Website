# Snow-Globe-Website
# ❄️ Interactive Snow Globe

## About
This is a winter-themed interactive snow globe website that creates a cozy and magical winter experience. Users can explore different scenes, turn the lights on and off, watch the snow fall, and interact with different buttons. The website also includes positive messages and animations to make it more fun and enjoyable.

## Features
-  Animated falling snow
-  Toggle the lights on and off
-  Explore different winter scenes
-  Rotate and interact with the snow globe
-  Random positive messages
-  Switch between different themes
-  Cozy winter-inspired design

##  Built With
- HTML
- CSS
- JavaScript

##  How to Use
1. Open the website in your browser.
2. Click the buttons to explore the snow globe.
3. Turn the lights on and off.
4. Change between different winter scenes.
5. Enjoy the animations and positive messages!

##  Purpose
The purpose of this project is to create a fun, interactive website that brings a cozy winter atmosphere to users while exploring the basics of web development.
